# Network Traffic Visualizer

A simple network monitoring tool that allows you to:

- Monitor traffic through multiple ports
- Visualize network data with graphs
- Track bandwidth usage
- Monitor packet send/receive statistics
- Identify protocols
- Set alerts for unusual port activity

## Setup

1. Install required packages:

   ```
   pip install -r requirements.txt
   ```

2. Run the application:

   ```
   python app.py
   ```

3. Open your browser and go to `http://localhost:5000`

## Note

This application requires administrator/root privileges to capture network packets.
